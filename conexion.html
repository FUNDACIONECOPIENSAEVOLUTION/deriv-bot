2. Preparar la conexión de cuenta

Ingresar a tu cuenta directamente en Deriv

Verifica que estás usando tu perfil y localiza dónde figura el saldo: billetera (Wallet), cuenta Options, CFD o Exchange. No transfieras dinero todavía.

Abrir Deriv oficial
Registrar una aplicación OAuth2

En Developers registra una aplicación para el proyecto. Obtendrás un App ID / client_id (identificador público). Configura una URI HTTPS de retorno que exista en nuestro servidor privado cuando esté desplegado.

Portal oficial de desarrolladores
Autorizar con OAuth2 + PKCE

La autorización se realiza en el sitio oficial de Deriv. Nuestro servidor privado intercambia el código por un token; nunca se escribe la contraseña en GitHub Pages. Los permisos de trading pueden ejecutar órdenes: deberán tratarse como credenciales sensibles.

3. Información necesaria para continuar

Sí podemos compartir en la conversación

• App ID público de la aplicación registrada en Deriv.

• Si el saldo está en Wallet, Options, CFDs o Exchange, sin compartir el número completo de cuenta.

• Confirmación de que puedes iniciar sesión y de que deseas iniciar con DEMO.

No debes enviarme aquí

• Contraseña, token PAT, access_token, refresh_token o client_secret.

• OTP, código de autorización OAuth, llave de pago o códigos 2FA.

• Claves privadas y datos completos de tarjetas o cuentas bancarias.

4. Autonomía con ChatGPT

Este proyecto ya incluye un servidor MCP de investigación de solo lectura. Para conectarlo a una conversación se requiere desplegarlo en HTTPS con autenticación y autorizarlo desde un cliente ChatGPT que admita servidores MCP personalizados. El servidor de investigación no tiene herramientas de compra, venta ni retiro.

La ejecución autónoma real requeriría infraestructura 24/7, motor de riesgo independiente y autorizaciones específicas. La rentabilidad no está garantizada y no se deben dar a una IA permisos de retiro.
